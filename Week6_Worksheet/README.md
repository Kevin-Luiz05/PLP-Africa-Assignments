# PLP Week 6 — JS Events & Interactivity

Files:
- `index.html` — demo page
- `style.css` — styling
- `script.js` — JavaScript logic (events, interactivity, validation)

How to run locally:
1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` → Open with Live Server.
4. Interact: toggle theme, start the 5s counter game, click FAQ items, fill and submit the form.

Submission:
- Push this folder to your assigned repo and submit the repo link in the LMS as instructed.
