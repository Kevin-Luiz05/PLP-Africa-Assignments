# Ubuntu_Requests — Ubuntu-Inspired Image Fetcher

**Purpose:** A respectful small tool that fetches an image from a URL and stores it in a local `Fetched_Images` folder.
Follows the spirit of *Ubuntu*: "I am because we are" — the tool connects to the shared web responsibly and organizes shared images for later appreciation and sharing.

## Files
- `ubuntu_fetcher.py` — main script (Python 3)
- This README — instructions

## Requirements
- Python 3.7+
- `requests` library
