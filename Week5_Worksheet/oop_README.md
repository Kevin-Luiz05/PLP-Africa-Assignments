# PLP Week 5 — Object Oriented Programming Assignment

This repository contains an example OOP project demonstrating class design, encapsulation, inheritance, and polymorphism in Python.

## Files
- `oop_assignment.py` — main script with classes and demo run (Book, EBook, Smartphone, Vehicle subclasses).

## How to run
1. Ensure you have Python 3 installed.
2. From this folder run:
```bash
python oop_assignment.py
```

## What it demonstrates
- Constructors, attributes, methods
- Private attributes and properties (encapsulation)
- Inheritance and method overriding
- Polymorphism: calling `move()` on different Vehicle subclasses
