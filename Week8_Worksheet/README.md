# PLP Week 8 — Final CRUD Project (FastAPI)

Simple CRUD app for **Students** and **Courses** with enrollments (many-to-many).
Built with FastAPI + SQLAlchemy + SQLite for easy grading and running.

## Files
- `main.py` — FastAPI app with endpoints
- `models.py` — SQLAlchemy ORM models
- `schemas.py` — Pydantic schemas (request/response)
- `database.py` — DB connection & Base
- `init_db.py` — populates sample data
- `requirements.txt` — dependencies
