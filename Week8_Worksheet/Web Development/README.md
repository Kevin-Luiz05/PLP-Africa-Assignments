# WK Final — Multi-page Website (YourSite)

## Project purpose
Portfolio & project showcase demonstrating semantic HTML, responsive CSS, JavaScript interactivity and accessibility.

## Pages
- index.html — Home
- about.html — About
- services.html — Services
- gallery.html — Gallery
- contact.html — Contact (client-side validation)

## How to run locally
1. Clone repo
2. Open the folder in VS Code
3. Use Live Server or open `index.html` in browser
4. Or run a simple static server: `npx http-server` (optional)

## Deployment
This site is deployed via GitHub Pages / Netlify / Vercel (choose one) — live link above.

## Notes
- Images are in `/images/` — replace with your own.
- Accessibility features: skip link, proper landmarks, alt attributes.
- SEO basics: per-page meta titles & descriptions.
